# Pac-Man Web App

This repo includes the original Kivy/Python game and a static HTML5 web app version that runs in iOS Safari and can be installed from the Share menu with Add to Home Screen.

## Web App

Open `index.html` in a browser, or deploy the repository with GitHub Pages. The web app uses:

- `index.html`
- `styles.css`
- `app.js`
- `manifest.webmanifest`
- `service-worker.js`
- `icons/`
- `Music/`

Controls work with arrow keys, WASD, swipe gestures, or the on-screen direction buttons.
